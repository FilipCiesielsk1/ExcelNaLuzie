# ExcelNaLuzie.pl

Statyczny portal SEO o Excelu oparty na Astro + Pagefind, wdrażany przez GitHub Pages.

## Lokalnie
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Publikacja
Push na `main` uruchamia GitHub Actions i wdraża `dist/` na GitHub Pages.

## Nowy artykuł
Dodaj plik Markdown do `src/content/poradniki/` używając istniejących artykułów jako wzoru.
